# Daily AI Patterns

매일의 문제를 AI와 함께 푸는 방법을 정리하는 공개 페이지입니다.

## 첫 번째 패턴

**AI를 활용한 PC 저장 공간 관리하는 방법**

핵심 메시지: PC 저장 공간 관리는 AI에게 삭제를 맡기는 게 아니라, 진단과 판단 보조를 맡기는 방식으로 쓰는 게 안전합니다.

## 배포 후보

- Cloudflare Pages
- 정적 파일: `index.html`, `styles.css`

## 로컬 확인

```bash
python3 -m http.server 8787
```

브라우저에서 `http://localhost:8787` 확인.
