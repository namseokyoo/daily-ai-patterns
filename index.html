Pattern 001

AI를 활용한 PC 저장 공간 관리하는 방법

핵심 메시지

AI에게 PC 관리를 맡긴다는 건 마음대로 삭제하게 하는 것이 아닙니다. AI를 활용해 원인을 찾고, 위험도를 나누고, 내가 결정할 수 있게 만드는 것입니다.

상황

PC 저장 공간이 갑자기 부족해졌습니다. 단순히 “뭘 지우면 돼?”라고 묻기보다, AI에게 현재 상태를 함께 진단하게 했습니다.

AI에게 맡긴 일

  • 현재 디스크 여유 공간 확인
  • 시스템 swap 사용량 확인
  • macOS 업데이트/Preboot 영역 확인
  • Docker/Colima 용량 확인
  • 작업 데이터와 스냅샷 확인
  • 지워도 되는 것과 위험한 것 구분

실제로 얻은 도움

AI는 용량이 큰 항목을 단순히 나열하는 데서 끝나지 않고, 삭제 위험도를 나눠줬습니다.

  • 정리 가능한 스냅샷은 삭제 후보로 분류
  • macOS Preboot처럼 부팅/업데이트와 연결된 영역은 직접 삭제 위험으로 분류
  • swap은 재부팅으로 자연 정리될 수 있다고 판단
  • Docker/Colima는 후보지만 사용자 승인 후 정리해야 한다고 구분

이 방법의 포인트

PC 저장 공간 관리는 무작정 삭제하면 위험합니다. AI를 쓰면 좋은 지점은 삭제 자동화가 아니라 진단 자동화입니다.

AI가 할 일

  • 어디가 큰지 찾기
  • 왜 커졌는지 추정하기
  • 지워도 되는 것과 위험한 것 나누기
  • 정리 우선순위 제안하기
  • 정기 점검 루틴 만들기

사람이 할 일

  • 실제 삭제 승인
  • 중요한 데이터 여부 판단
  • 재부팅/업데이트 같은 시스템 결정
  • 불확실한 항목은 보류하기

정기 점검 자동화 아이디어

매일 또는 주 1회, AI가 아래 항목을 확인하고 문제가 있을 때만 짧게 알려주게 합니다.

디스크 여유 공간 swap 증가 Preboot/업데이트 영역 Docker/Colima 누적 작업 폴더/백업 증가

한 줄 정리

PC 저장 공간 관리는 AI에게 삭제를 맡기는 게 아니라, 진단과 판단 보조를 맡기는 방식으로 쓰는 게 안전합니다.
